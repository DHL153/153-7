기사 난이도 · 안마다 150판 × (숙련 smart / 보통 normal). 봇: `docs/balance/bot` (`GATE=bar`).

| 안 | 설명 |
|---|---|
| capR | **지금 규칙** — 한 번 최대 55% · 3개 맞추면 관통 |
| b10p | **기획서 그대로** — 방패 = 체력 10% · 관통률 = 확률(실패 시 방패만) · 깨지면 피해 증가 |
| b60r | 비율 관통 — 피해 × 관통률은 HP로 바로, 나머지는 방패 · 방패 60% |
| b60rT16 / T22 | b60r + 적 체력 ×1.6 / ×2.2 |
| b60r1T22 | 3개 = 100% 관통 (0·33·67·100%) + 체력 ×2.2 |
