`preview/index.html`을 정적 서버로 열면 두 캐릭터가 같이 움직여요 (서 있기 · 걷기 W · 스트레이트 J · 터치 H).
녹슨 첨탑 게임(`sts/basil/`)에도 같은 파일이 들어가 있어요.

## v7 → v8에서 고친 것
| 문제 | v8 |

| 다리·반바지 사이 틈, 살색 네모가 삐져나옴 | 반바지 밑단 클립을 없앴어요. 다리 색을 불투명한 반바지 밑으로만 9px 더 칠하고, 잘못 다리에 붙어 있던 밑단 외곽선은 반바지로 돌려보냈어요 |
| 서 있기·펀치 중 다리와 반바지가 벌어짐 | 서 있기와 펀치에서는 골반이 움직이지 않아요(숨쉬기는 몸통 비율로만) |

## 움직임은 일부러 절제
- 걷기: 보폭 72 → 56, 발 들기 16 → 11, 몸 흔들림·팔 흔들림 축소
- 스트레이트: 다리 내딛기 없음, 몸 숙이기와 팔 뻗기만. 팔은 가장 빠른 한 프레임에 교체(pOn)
- 터치: 다리를 굽히지 않고 몸 전체가 가볍게 떴다 내려와요

## 자동 점검 (source/qa.py)
6개 시나리오(서 있기+표정+깜빡임, 걷기·달리기·멈춤, 펀치 2회, 걷다가 펀치, 터치, 왼쪽 보기) 약 490프레임을 그려서 확인해요.
- 떨어져 떠다니는 조각: 두 캐릭터 모두 0
- 몸 안쪽 구멍: 다리 사이·턱과 팔 사이처럼 원화에도 있는 빈 공간만 남음(qa2.py로 상체 구멍을 따로 확인)
- 관절 각도: 무릎이 꺾이는 방향이 항상 같아서 뒤집힘 없음(정강이 N 0~0.35, F −0.41~0)
- 페이지 에러 0
