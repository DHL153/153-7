니콜 안내 NPC

튜토리얼 안내용 니콜이에요. 숨 쉬기, 눈 깜빡임, 머리카락과 치맛자락 살랑임이 늘 살아 있고, 팔과 표정은 모두 그린 그림 그대로 보여 줘서 선이 깨지지 않아요. 니콜을 누르면 반응해요.

등장 · 퇴장 빛이 모이며 작게 떠오르듯 나타나서 콩 하고 내려앉고, 손을 흔들며 활짝 웃어요. 퇴장은 손 흔들며 빛가루로 사라져요.
감정 인사, 안내(말하면서 손바닥으로 가리키기), 기뻐요(두 손 모아 콩콩), 슬퍼요(펜던트 꼭 쥐고 고개 숙임, 눈물), 놀람, 생각, 걱정. 연출이 끝나면 기본 자세로 부드럽게 돌아와요.
말하기 · 깜빡임 표정마다 맞는 입으로 말하고(슬플 땐 울먹이는 입), 표정마다 맞는 눈으로 깜빡여요(반쯤 감음 → 감음 → 반쯤). 머리카락과 얼굴선은 언제나 원본 그대로예요.
이펙트 OFF 빛가루, 반짝이, 눈물방울, 땀, 생각 방울이 꺼지고 니콜의 움직임만 남아요. 글자나 말풍선은 넣지 않았어요.
